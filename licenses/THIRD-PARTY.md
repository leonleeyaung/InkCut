# 第三方组件

便携版随附的组件各自保留其上游许可，不受 InkCut 的 MIT 许可替代。

- Electron 45.3.2，官方 Windows x64 发行版：[发行包与源码](https://github.com/electron/electron/releases/tag/v45.3.2)。许可见 `runtime/LICENSE`、`runtime/LICENSES.chromium.html`。
- FFmpeg 7.1，Gyan Windows Essentials build，独立命令行程序（未修改）：[对应构建及上游说明](https://github.com/GyanD/codexffmpeg/releases/tag/7.1)，[对应 FFmpeg 源代码](https://github.com/FFmpeg/FFmpeg/tree/b08d7969c5)，[构建工具](https://github.com/m-ab-s/media-autobuild_suite)。GPL 许可见 `FFmpeg-GPLv3.txt`（本目录）。在解压目录执行 `tools\ffmpeg.exe -buildconf` 可查看启用的第三方库与完整构建选项。
